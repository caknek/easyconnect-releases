# EasyConnect · Instaladores para Windows

Aquí se publican las versiones de la app de escritorio de **EasyConnect**.
La app instalada revisa este repositorio sola, descarga la versión nueva y ofrece «Reiniciar y actualizar».

**Primera instalación:** descarga `EasyConnect-Instalador.exe` de la última versión en [Releases](../../releases/latest) y ábrelo.
Las versiones siguientes se instalan solas, encima de la anterior (no hay que desinstalar).
